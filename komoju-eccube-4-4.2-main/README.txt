# KOMOJU決済プラグイン for EC-CUBE 4.2

[EC-CUBE](http://www.ec-cube.net)用の[KOMOJU](https://komoju.com/)決済プラグインです。

お客様はチェックアウト時にKOMOJUの決済ページへ遷移し、クレジットカードやコンビニ決済など多様な方法でお支払いいただけます。カード情報はKOMOJUのサーバーで安全に処理されるため、EC-CUBEのデータベースには一切保存されません。

## 対応環境

- EC-CUBE 4.2以上

EC-CUBE 4.0〜4.1をご利用の場合は、4.0系専用バージョンをお使いください。

## 利用可能な決済方法

KOMOJUアカウントで有効になっている決済方法が自動的に連携されます。主な対応決済：

- クレジットカード（Visa、Mastercard、JCB、AMEX、Diners、Discover）
- コンビニ決済
- 銀行振込
- ペイジー
- PayPay
- LINE Pay
- メルペイ
- キャリア決済
- 電子マネー（WebMoney、BitCash、NET CASH）

## 機能一覧

### 決済処理

- KOMOJUの決済ページを利用した安全なお支払い（カード情報非通過対応）
- 「認証と売上処理」または「認証のみ」の2つの処理方法を選択可能
- 注文完了後、Webhookにより決済ステータスを自動で同期

### 管理画面の機能

- **設定ページ**：APIキー登録、決済方法の選択、処理方法の設定、Webhook設定
- **注文編集ページ**：
  - 売上処理（認証のみ設定時の手動キャプチャ）
  - 全額返金・一部返金
  - 決済ステータスの確認（オーソリ済み・売上確定・返金済みなど）
  - イベントタイムライン（決済に関する操作履歴の表示）
  - KOMOJU管理画面への取引詳細リンク
- **ログページ**：
  - 注文ID・操作種別・日付・キーワードによる絞り込み検索
  - CSVエクスポート
  - ログの一括削除
  - 保持期間を設定した自動削除
  - ログ記録のON/OFF切り替え

### Webhook対応イベント

| イベント | 動作 |
|---|---|
| payment.captured | 注文ステータスを【入金済み】に更新 |
| payment.refunded | 返金情報を記録し、注文ステータスを【注文取消し】に更新 |
| payment.cancelled | 注文をキャンセル処理 |
| payment.expired | 注文をキャンセル処理 |
| payment.failed | 注文をキャンセル処理 |
| payment.updated | ステータス変更に応じた処理 |

### セキュリティ

- WebhookのHMAC-SHA256署名検証
- CSRF対策（全管理画面操作）
- カード情報非通過（PCI DSS対応）
- 返金処理の排他制御

## インストール方法

1. EC-CUBE管理画面の【オーナーズストア】→【プラグイン】→【プラグイン一覧】から【アップロードして新規追加】をクリックし、プラグインのZIPファイルをアップロードします。

2. プラグイン一覧から【KOMOJU決済プラグイン】の【有効にする】をクリックします。

3. 【コンテンツ管理】→【キャッシュ管理】で【キャッシュ削除】を実行します。

4. 【KOMOJU決済】→【設定】を開き、以下を設定します：
   - **非公開鍵・公開用鍵・クライアントUUID**：KOMOJU管理画面の設定ページから取得して入力
   - **決済方法の同期**：非公開鍵を入力後、【KOMOJUに接続】をクリックして利用可能な決済方法を取得
   - **処理方法**：「認証のみ」または「認証と売上処理」を選択
   - **Webhook設定**：表示されるWebhookエンドポイントURLとシークレットトークンをKOMOJU管理画面のWebhookページに登録

5. 【設定】→【店舗設定】→【配送方法設定】で、対象の配送方法に【KOMOJU決済】を紐づけて保存します。

## アップデート方法

1. 【オーナーズストア】→【プラグイン】→【プラグイン一覧】からプラグインを**無効**にします。
2. プラグインを**更新**します。
3. プラグインを**有効**にします。
4. 【コンテンツ管理】→【キャッシュ管理】で【キャッシュ削除】を実行します。

## 処理方法について

### 認証と売上処理

チェックアウト時にオーソリと売上処理が同時に行われます。注文は自動的に【入金済み】ステータスになり、ポイントもこの時点で反映されます。

### 認証のみ

チェックアウト時にはオーソリのみが行われます。管理画面の注文編集ページから手動で売上処理（キャプチャ）を実行できます。売上処理後、注文は【入金済み】ステータスに更新され、ポイントが反映されます。払い戻し時は注文が【注文取消し】ステータスに更新されます。
